# «Накарабине»: спецификация требований к интернет-магазину

Учебная работа Яндекс Практикума (май–июнь 2026). «Накарабине» — бренд одежды и снаряжения для походов и скалолазания. Сейчас покупатели заказывают товары через маркетплейсы; первая версия собственного веб-приложения должна это заменить. Спецификация написана по шаблону К. Вигерса.

## Общее описание

| Раздел | Содержание |
|---|---|
| Границы проекта | Заказ одежды бренда и сопутствующих товаров: амуниции, аксессуаров, полезных мелочей |
| Классы пользователей | Покупатель, любящий активный отдых; заказывает обычно раз в год в начале сезона; ожидается около 500 активных покупателей |
| Операционная среда | ОС-1: Chrome 56+, Safari 8.0–14.0. ОС-2: Red Hat Linux + Apache HTTP Server |
| Ограничения | Огр-1: СУБД PostgreSQL. Огр-2: код соответствует HTML 5.0 |
| Зависимости | Зав-1: заказ возможен только при наличии товара на складе. Зав-2: оплата зависит от доступности платёжной системы |

## Варианты использования

| ID | Вариант использования | Альтернативный сценарий |
|---|---|---|
| ВИ-1 | Посмотреть список всех товаров | — |
| ВИ-2 | Посмотреть информацию о товаре (название, описание, цена, наличие, фото) | — |
| ВИ-3 | Найти товар | Товар не найден → сообщение и возврат к поиску |
| ВИ-4 | Найти товар по категориям: одежда, амуниция, аксессуары, полезные мелочи | — |
| ВИ-5 | Оформить заказ из корзины | Заказ не оформлен → сообщение и возврат к вводу данных |
| ВИ-6 | Ввести данные пользователя | Некорректные данные → подсветка полей |
| ВИ-7 | Ввести контактную информацию (ФИО, телефон, email) | Некорректные данные → сообщение |
| ВИ-8 | Ввести информацию о доставке; система показывает адрес на карте | Адрес некорректен → сообщение |
| ВИ-9 | Изменить количество товара в корзине | Нет нужного количества на складе → сообщение |
| ВИ-10 | Выбрать способ оплаты | — |
| ВИ-11 | Оплатить товары картой (с кодом подтверждения) | Оплата не прошла → возврат к вводу данных карты |
| ВИ-12 | Оплатить наличными курьеру при доставке | — |

## Пример варианта использования

| | |
|---|---|
| **ВИ-11** | Оплатить товары картой |
| Контекст | Оплата заказанных товаров в веб-приложении |
| Основное действующее лицо | Пользователь |
| Предусловие | Выполнен базовый сценарий «Выбрать способ оплаты» |
| Гарантии успеха | Пользователь оплатил заказ картой |
| Базовый сценарий | 1. Пользователь выбрал «Оплата картой». 2. Вводит данные карты. 3. Вводит код подтверждения. 4. Система проверяет данные. 5. Система сообщает, что заказ оплачен |
| Расширения | 5а. Система сообщает, что заказ не оплачен. 5b. Возврат к шагу 2 |
| Изменения в технологии и данных | Использовать модуль оплаты товаров |

## Модель данных

Логическая модель первой версии включает 7 сущностей: пользователь, товар, категория, корзина пользователя, заказ, товар в заказе, адрес доставки. Работа с ER-моделями и нормализацией — в проекте [06-data-modeling-er](../06-data-modeling-er/README.md).
