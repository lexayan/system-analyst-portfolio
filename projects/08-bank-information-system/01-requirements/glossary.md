# Глоссарий проекта

| Термин | Определение |
|---|---|
| Транзакция | Финансовая операция по переводу или списанию денежных средств, требующая регистрации и последующей обработки банковской системой. |
| Банковский счет | Запись в информационной системе, содержащая сведения о текущем балансе, валюте, привязанном клиенте и истории финансовых операций. |
| Клиент | Лицо, использующее информационную систему для управления своими счетами, перевода средств и получения финансовых выписок. |
| Банковский специалист | Сотрудник банка, отвечающий за открытие счетов, проверку документов, подтверждение транзакций и консультирование клиентов. |
| Администратор | Пользователь с расширенными правами доступа, отвечающий за управление учетными записями, ролями и настройками системы. |
| Действующие лица | Все пользователи и внешние участники, которые взаимодействуют с информационной системой банка. |
| Тип транзакции | Признак, позволяющий классифицировать финансовую операцию по назначению, например внутренний перевод, оплата услуг или межбанковский платеж. |
| Категория клиента | Показатель важности клиента, определяющий доступные лимиты счета, бонусные программы и приоритетность обслуживания специалистами банка. |
| Статус транзакции | Текущее состояние финансовой операции в процессе обработки, например создана, в обработке, исполнена или отклонена. |
| Назначение платежа | Текстовое сообщение, добавляемое клиентом при переводе средств для уточнения цели финансовой операции или фиксации деталей платежа. |
| Уведомление | Сообщение системы, информирующее клиента или специалиста об изменении баланса счета, успешном переводе или возникновении системной ошибки. |
| Справочник реквизитов | Набор сведений о банках-партнерах и сохраненных шаблонах платежей, используемый для ускорения проведения регулярных транзакций клиентов. |
