# Глоссарий проекта

| Термин | Определение |
|---|---|
| Пользователь | Лицо, взаимодействующее с системой (слушатель, исполнитель или администратор). |
| Гость | Незарегистрированный посетитель с доступом к просмотру каталога треков и поиску. |
| Исполнитель | Зарегистрированный пользователь, загружающий собственные треки и управляющий своим творческим профилем. |
| Слушатель | Зарегистрированный пользователь, прослушивающий треки, формирующий плейлисты и добавляющий композиции в избранное. |
| Администратор | Пользователь с расширенными правами доступа, осуществляющий модерацию контента и управление каталогом. |
| Трек | Музыкальная композиция в цифровом формате с метаданными (название, исполнитель, жанр, длительность). |
| Альбом | Логическое объединение треков одного исполнителя с общим названием и обложкой. |
| Плейлист | Пользовательский или системный список треков для последовательного прослушивания. |
| Жанр | Категория музыкального произведения, определяющая его стилевую принадлежность. |
| Метаданные трека | Совокупность описательных данных (название, исполнитель, альбом, год выпуска, битрейт, текст песни). |
| Статус трека | Текущее состояние композиции в системе (на модерации, опубликован, заблокирован, удалён). |
| Избранное | Персональный список треков и альбомов, отмеченных пользователем для быстрого доступа. |
| История прослушиваний | Журнал воспроизведённых композиций с фиксацией даты, времени и количества прослушиваний. |
